# Search Duplicate Files

Windows Forms で動作する重複ファイル検出ツールです。指定した1つ以上のフォルダーや圧縮ファイルを検索し、ファイル名、ファイル名とサイズ、または SHA-256 による内容比較で一致候補を一覧表示します。

## 主な機能

- 1つ、または複数の対象フォルダーを指定した重複ファイル検索
- ZIP、7z、tar系アーカイブ自体を検索対象として追加し、展開せずに内部ファイルを比較
- フォルダー内ファイルと圧縮ファイル内、または圧縮ファイル内同士の重複検索
- 判定方法を「内容（SHA-256）」「ファイル名＋サイズ」「ファイル名のみ」から選択
- 圧縮ファイルと展開済みフォルダーが完全一致するかを確認する専用比較ウィンドウ
- 圧縮側のみ、フォルダー側のみ、サイズ違い、内容違い、読取不可を個別表示
- 複数の検索対象を比較するときの「異なる検索対象間の重複だけ表示」
- サブフォルダー検索のオン/オフ
- 隠しファイル、システムファイルを含める設定
- ファイル名とフォルダー名を別々に指定できる部分一致・ワイルドカード検索（`;` 区切り）
- 「フィルター適用」ボタンで、再スキャンせず保持している結果へ条件を適用
- グループ内の1件がパターンに一致すれば、比較対象を含むグループ全体を表示
- フィルター表示を「重複グループ全体」「条件に一致したファイルのみ」から選択
- 結果一覧の各列をクリックして昇順・降順に並べ替え
- 最小ファイルサイズ指定
- スキャンのキャンセル
- タイトルバー、フッター、タスクバーアイコンでの進捗表示
- グループごとの色分け表示
- 重複結果の CSV 保存
- 対象ファイルを開く、エクスプローラーで場所を開く
- 選択したファイルをごみ箱へ移動

## 動作環境

- Windows
- .NET 10 Desktop Runtime

開発、ビルドには .NET 10 SDK 以降が必要です。

## ビルド

```powershell
dotnet build
```

## 実行

```powershell
dotnet run --project src/SearchDuplicateFiles.WinForms/SearchDuplicateFiles.WinForms.csproj
```

## 配布用ビルド例

.NET ランタイムを同梱しない場合:

```powershell
dotnet publish src/SearchDuplicateFiles.WinForms/SearchDuplicateFiles.WinForms.csproj -c Release -r win-x64 --self-contained false
```

.NET ランタイムを同梱する場合:

```powershell
dotnet publish src/SearchDuplicateFiles.WinForms/SearchDuplicateFiles.WinForms.csproj -c Release -r win-x64 --self-contained true
```

出力先は `src/SearchDuplicateFiles.WinForms/bin/Release/net10.0-windows/win-x64/publish/` です。

## 使い方

1. `フォルダー...` から対象フォルダーを、`圧縮ファイル...` から圧縮ファイルを追加します。どちらか一方だけでも検索できます。
2. `判定方法` と、必要な検索オプションを選択します。
3. フォルダーと圧縮ファイルなど、異なる検索対象にまたがる重複だけを見たい場合は `異なる検索対象間の重複だけ表示` をオンにします。
4. `スキャン開始` を押します。
5. 検出結果はグループごとに色分けされます。

圧縮ファイル内のファイルは結果に `圧縮ファイルのパス :: 内部のパス` と表示されます。内部エントリを個別に開いたり、ごみ箱へ移動したりすることはできません。

対応する圧縮形式:

- `.zip`
- `.7z`
- `.tar`
- `.tar.gz` / `.tgz`
- `.tar.bz2` / `.tbz2` / `.tbz`
- `.tar.xz` / `.txz`
- `.tar.lz` / `.tar.lzip` / `.tlz`
- `.tar.zst` / `.tar.zstd` / `.tzst`

暗号化された圧縮ファイルの内容比較には対応していません。安全のため、圧縮ファイル1件につき25万エントリを上限とします。内容比較では、さらに1エントリ64 GB、展開後合計512 GBを上限とし、超過分は警告に記録してスキップします。

## 圧縮ファイルと展開済みフォルダーの比較

1. メイン画面下部の `圧縮⇔展開フォルダー比較` を押します。
2. 比較する圧縮ファイルと、その展開済みフォルダーを選択します。
3. `判定方法` を選択します。
4. `比較開始` を押します。
5. 初期状態では不一致だけが表示されます。`一致したファイルも表示` をオンにすると全件を確認できます。

圧縮ファイル内と展開済みフォルダー内のファイルは、選択したフォルダーを基準とする相対パスで対応付けます。判定方法に応じてファイルサイズとSHA-256も確認します。空フォルダーは比較対象外です。比較結果はCSVへ保存できます。

圧縮ファイル内が `offline-rpms\...`、選択した展開済みフォルダー内が `...\` のように、展開後に中身を1階層上へ移動している場合は、`圧縮内の先頭フォルダー1階層を無視` をオンにしてください。圧縮内の各ファイルについて先頭階層を比較時だけ取り除きます。

## 判定方法

- `内容（SHA-256）`: ファイルサイズが同じ候補のSHA-256を計算し、サイズとハッシュが同じファイルをグループ化します。ファイル名が異なっていても内容が同じなら一致します。
- `ファイル名＋サイズ`: フォルダー位置を問わず、末尾のファイル名とサイズが同じファイルをグループ化します。ハッシュは計算しません。
- `ファイル名のみ`: フォルダー位置とサイズを問わず、末尾のファイル名が同じファイルをグループ化します。ハッシュは計算しません。

`異なる検索対象間の重複だけ表示` がオンの場合は、選択した判定方法で一致し、かつ2つ以上のフォルダーまたは圧縮ファイルにまたがるグループだけを表示します。

スキャン中にアクセスできないファイルや、サイズが変更されたファイルはスキップして警告に記録します。ジャンクションやシンボリックリンクなどの再解析ポイントは、循環や意図しない大量スキャンを避けるため対象外にしています。
